# Recursos gráficos

Las portadas, separadores y stickers de esta fase se dibujan con formas vectoriales originales desde `src/`. No se incluyen fotografías, ilustraciones descargadas ni archivos de fuentes de terceros.

Los PNG transparentes exportados se guardan en `output/stickers-test/`. El PDF incrusta los subconjuntos de las fuentes de texto utilizadas. Los gráficos vectoriales conservan nitidez al ampliar.
